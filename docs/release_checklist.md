# Echo Village v1.4.0 Release Checklist

這份 checklist 用於可重現的版本交付。v1.4.0 的驗收已完成；下方保留勾選結果作為 release evidence。GitHub Release 與 deployment 不包含在本機驗收範圍內。

## Current Windows candidate — v2.0.0 (not a public release)

Use this checklist only for the candidate generated by the current PR head. The historical v1.4.0 evidence below does not validate this candidate.

### Automated checks
- [ ] CI for the exact candidate SHA reports 134 tests passed, 0 failed, secret scan and security audit pass, and the visual QA matrix passes.
- [ ] The Windows candidate artifact contains the EXE, adjacent PCK, README, third-party notices, candidate manifest, and SHA256 sums.
- [ ] Verify the manifest source SHA equals the tested commit and validate every listed checksum.

### Windows GUI acceptance
- [ ] On Windows 10/11 without Godot installed, start the package from a clean folder and confirm the first-run flow, movement, resident interaction, trading, tasks, map, settings, and keyboard controls work.
- [ ] Save, close, restart, and load; corrupt the primary save in a disposable profile and confirm backup recovery preserves the last valid state.
- [ ] Trigger an operation failure and confirm the message describes the actual result without hiding previous saved data.
- [ ] Check 1280×720, 1366×768, 1600×900, and 1920×1080 for clipping, overlap, unreadable text, or controls that cannot be reached.
- [ ] Record the candidate SHA and result before marking manual acceptance complete.

The CI artifact is a test candidate, not a release. Do not publish it as a formal Release until every item above passes.

## Reviewer handoff

審查者應先看：

1. `README.md`：產品定位、操作、截圖與可重現命令。
2. `docs/architecture.md`：NPC、故事線、存檔與服務邊界。
3. `docs/story_system.md`：Living Stories 資料契約與後果模型。
4. `tests/simulation_test_report.json`：最新測試證據。
5. `CONTRIBUTING.md`／`SECURITY.md`：後續維護與漏洞回報流程。
