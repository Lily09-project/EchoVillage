# 每日回音歷史與分類回顧設計

## 目標

將目前只能查看「今天」摘要的每日回音，升級為可回看歷史遊戲日、依事件類別篩選，並在沒有資料時提供清楚空狀態的正式回顧工具。這能讓玩家理解 NPC 行為與世界後果如何跨日累積，而不增加新的存檔格式版本。

## 使用者流程

1. 玩家按 `L` 開啟「今日回音」。
2. 面板顯示目前回顧日、事件總數與分類統計。
3. 玩家使用上一日／下一日控制切換歷史天數；下一日不可超過目前遊戲日。
4. 玩家使用分類控制在「全部、居民、世界、任務、經濟、地點、進展」間切換。
5. 面板依目前條件重繪事件列表；沒有符合資料時顯示可理解的空狀態與目前篩選條件。
6. 按 `J` 或原有切換按鈕回到村落編年，不影響既有快捷鍵與暫停行為。

## 架構

- `GameManager.timeline_snapshot(category, target_day, limit)` 保持唯一查詢入口，沿用既有 160 筆上限與唯讀複製。
- `Main` 維護 `daily_echo_day` 與 `daily_echo_category` 兩個純 UI 狀態，不把篩選狀態寫入存檔。
- `refresh_journal_panel()` 統一依模式更新標題、統計、事件文字與控制按鈕狀態。
- 分類按鈕使用固定且可讀的中文標籤；歷史日控制以邊界 disabled 狀態阻止非法操作。
- 舊版存檔缺少時間軸時仍使用空陣列，UI 顯示空狀態而不是錯誤。

## 互動與可及性

- 所有控制使用 `Button`，具備明確文字、tooltip、disabled 狀態與一致的 VillageTheme 樣式。
- 上一日／下一日按鈕在邊界 disabled；分類切換按鈕顯示下一個可切換狀態，避免玩家不知道目前篩選。
- 空狀態文字包含目前日期與篩選名稱，避免玩家誤以為資料遺失。

## 驗收與測試

- 資料測試：指定日與分類只回傳符合事件，超出保留上限仍維持 bounded snapshot。
- UI 測試：歷史日／分類控制存在、邊界 disabled、切換後標題與內容同步，空狀態可讀。
- 回歸測試：既有存檔、村落編年、快捷鍵與完整 Godot 測試維持通過。
- 驗收指標：完整套件測試 0 失敗、結構驗證通過、`run_echo_village.bat --test` 退出碼 0。
