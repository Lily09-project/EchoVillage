# 首次旅程導覽與作品集驗收設計

## 目標

讓第一次啟動 Echo Village 的玩家在 60 秒內理解「如何移動、如何接觸居民、如何形成長期回音」，同時讓審查者能直接看到完整的產品引導、可及性決策與可重現的品質證據。導覽不改變模擬核心，也不阻塞熟悉玩家。

## 使用者流程

1. 玩家從主選單選擇「開始新旅程」後，遊戲顯示三步驟導覽卡。
2. 步驟一說明 WASD／方向鍵移動與日夜模擬；步驟二說明靠近居民按 `E`、用 `C` 交談與 `Q` 詢問；步驟三說明 `G` 贈禮、`J` 編年與 `L` 今日回音。
3. 玩家可按「下一步」前進、按「略過導覽」立即開始；最後一步顯示「開始探索」。
4. 導覽完成或略過後以偏好設定持久化，後續新遊戲不重複打斷玩家。
5. 玩家可從暫停選單按「操作指南」重新開啟導覽；重新開啟不會重置世界狀態。
6. `Esc` 在導覽中提供安全退出路徑，模擬在面板可見期間可靠暫停。

## 架構

- `SaveManager.preferences` 新增 `onboarding_seen`，舊偏好檔缺少欄位時使用 `false` 的安全預設。
- `Main` 維護 `onboarding_panel`、目前步驟與三段靜態內容；導覽是 UI 狀態，不寫入世界存檔。
- `show_onboarding(force: bool)` 只在新旅程且尚未看過時自動顯示；暫停選單可用 `force=true` 重開。
- `sync_simulation_pause()` 將導覽納入 modal 狀態；按鈕與鍵盤 Esc 共用關閉流程，避免狀態分歧。
- 所有按鈕至少 44px 高，使用既有 VillageTheme，文字直接描述操作，不依賴顏色或 hover 才能理解。

## 審查者與品質證據

- 自動測試驗證首開顯示、步驟切換、略過／完成持久化、暫停互斥與重開入口。
- README、作品集 case study、展示腳本使用目前真實測試數與 CI workflow，不保留過期的 76 項描述。
- Visual QA 增加首次導覽畫面，讓審查者能檢查文字層級、按鈕尺寸與遮罩層級。

## 非目標

- 不新增線上帳號、遙測或外部服務。
- 不修改 NPC 決策、任務資料、存檔 envelope 版本或既有快捷鍵。
