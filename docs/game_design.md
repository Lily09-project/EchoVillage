# 遊戲設計 — Echo Village 展示版

玩家探索城鎮廣場、酒館、商店、農場、醫館與森林邊緣。村落會依遊戲時間經歷黎明、上午、正午、午後、黃昏與深夜；視覺光照、太陽／月亮、雲層、噴泉與 NPC 動態同步改變。五位村民從 06:00 開始依各自日程行動；玩家可用時間控制列加速時間，並用 F3 檢查任何 NPC 的需求、決策分數與目標。

NPC 會在用餐、睡眠、工作、社交、採買、回家、逃離、協助、休息、閒逛之間選擇。效用分數結合需求、日程、人格、背包與世界事件，狀態機則呈現待命、移動、交易、社交、睡眠、工作等狀態，並具備逾時復原。

## 可玩任務迴路

「林間回音」把既有系統串成一段可展示的遊戲流程：向艾莉絲詢問委託 → 由世界地圖旅行 → 抵達具有獨立美術語言的低語森林 → 將一份麵包交給黛安娜 → 取得硬幣、草藥、聲望、記憶與永久完成旗標。任務採有序目標；交付與獎勵皆具原子性與冪等性，不會因背包不足或重複操作產生半完成狀態。

## 展示情境

1. 贈送艾莉絲麵包：她會建立正向記憶、提高信任與好感，並改變對話。
2. 偷取鮑伯麵包：鮑伯記得偷竊並降低對玩家信任，後續可在社交中傳播故事。
3. 觸發突發危險（B）：低勇氣 NPC 優先逃離，高勇氣 NPC 優先協助。
4. 觸發糧食短缺（H）：麵包價格上升，飢餓在決策中的權重提高。

## 展示回饋迴路

- NPC 檔案同時顯示情緒、目前行動、四項需求、玩家關係與最近記憶。
- `J` 村落編年將善意、流言、危機轉為三個可解鎖的敘事節點與聲望；其進度會保存。
- `I` 背包、`Esc` 暫停與動態效果開關讓展示者可依講解節奏控制體驗。
- `M` 世界地圖與 `K` 任務日誌提供清楚的旅行、進度與完成記錄；畫面上方的追蹤器只呈現目前目標，避免資訊過載。
- 地圖上的名字／行動標籤與 F3 Utility 分數對照，讓「內部決策」和「外部表現」同時可見。

本作品聚焦於可解釋的 Agent simulation，不以戰鬥、隨機地圖、3D 或語音擴張範圍；LLM 如在後續導入，僅能產生對話或摘要，不能改寫遊戲權威狀態。
