Echo Village 2.0.0｜Windows 候選測試版

此為預發行測試包，尚非正式版本。完成 Windows 圖形介面驗收後才會考慮發布。

啟動方式
========
將 EchoVillage.exe 與 EchoVillage.pck 放在同一個資料夾，直接雙擊 EchoVillage.exe。
不需要另外安裝 Godot。

系統需求
========
Windows 10／11 64 位元；顯示卡支援 OpenGL 3.3。

基本操作
========
WASD／方向鍵：移動
E：選取附近居民
C：與已選居民交談
G：贈送物品
T：交易
Q：詢問
U：傳聞網路
K：任務與委託
V：村落日誌
J：村落編年
L：今日回音
Y：關係歷程
O：故事線
P：村落手札
M：地圖
F1：操作導覽
F5：儲存
Esc：關閉面板或暫停

存檔
====
存檔保存在 Windows 使用者資料目錄；遊戲會管理有效存檔與備份復原。
測試此候選版本時，請使用可丟棄的測試存檔。

遊戲說明
========
這是一款由本地規則驅動的生活模擬遊戲，不需要 API 金鑰或網路連線。
本候選包僅供驗收，正式版本請以 GitHub Releases 公告為準。
